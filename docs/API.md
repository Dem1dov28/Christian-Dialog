# API Epochal Dialog

Интерактивная документация: **/docs** (Swagger UI) и **/redoc** (ReDoc) при запущенном backend.

## Базовый URL

- Локально: `http://localhost:8000`
- Production: подставляйте свой домен API

## Общие эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/` | Информация об API (message, docs) |
| GET | `/api` | Расширенная информация (message, docs, agents, chat, multi_agent_chat) |
| GET | `/health` | Проверка живости сервиса для мониторинга и load balancer. Ответ: `{"status": "ok"}` |
| GET | `/docs` | Swagger UI |
| GET | `/openapi.json` | Схема OpenAPI |

## Аутентификация

Используется JWT (Bearer token). Эндпоинты авторизации под префиксом `/auth` (логин, регистрация, refresh, Google OAuth и т.д.).

## Основные группы API

- **Агенты** — список агентов, создание пользовательских агентов (зависит от роутинга в `api/agents.py`)
- **Чат** — создание/получение разговоров, сообщения, стриминг ответов
- **Мульти-агентный чат** — групповые чаты с несколькими агентами
- **Папки** — управление папками чатов
- **Закреплённые чаты** — закрепление/открепление
- **Поиск** — полнотекстовый поиск по сообщениям
- **Достопримечательности и посещения** — привязка к поездкам (attractions, attraction_visits)
- **Отчёты и поддержка** — отчёты, обратная связь

## Статика и файлы

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/download/{filename}` | Скачивание экспорта (exports/) |
| GET | `/api/avatars/{filename}` | Аватар пользователя (uploads/avatars/) |
| GET | `/static/user_agents/{path}` | Аватар пользовательского агента |
| GET | `/static/group_chats/{path}` | Аватар группового чата |
| GET | `/api/files/{filename}` | Скачивание вложения из сообщения (требует авторизации) |

## Примеры запросов

### Health check

```bash
curl -s http://localhost:8000/health
# {"status":"ok"}
```

### Получение информации об API

```bash
curl -s http://localhost:8000/api
```

### Авторизованный запрос (пример)

```bash
curl -s -H "Authorization: Bearer <token>" http://localhost:8000/agents
```

Точный список эндпоинтов и параметров смотрите в **/docs** после запуска backend.
