# Управление промптами агентов

## 🎯 Гибридный подход: YAML + БД

Промпты агентов хранятся в двух местах:

1. **`backend/config/agents.yaml`** - исходная конфигурация (версионируется в git)
2. **База данных** - runtime хранилище для быстрого доступа

## 📝 Преимущества

✅ **Версионирование** - все изменения промптов отслеживаются в git  
✅ **Легкое редактирование** - можно редактировать YAML файл в любом редакторе  
✅ **История изменений** - git diff показывает что изменилось  
✅ **Откат изменений** - можно вернуться к любой версии через git  
✅ **Code review** - можно ревьюить изменения промптов в PR  

## 🔄 Рабочий процесс

### 1. Редактирование промпта

Откройте `backend/config/agents.yaml` и отредактируйте промпт:

```yaml
agents:
  - name: "Толкователь сновидений"
    instructions: |
      Твой новый промпт здесь...
```

### 2. Синхронизация с БД

Запустите скрипт синхронизации:

```bash
cd backend
python scripts/sync_agents_from_config.py
```

### 3. Проверка изменений (dry-run)

Перед применением можно проверить что изменится:

```bash
python scripts/sync_agents_from_config.py --dry-run
```

## 📋 Структура YAML файла

```yaml
agents:
  - name: "Имя агента"
    instructions: |
      Многострочный промпт
      с поддержкой форматирования
    model: "deepseek/deepseek-chat"
    category: "tools"  # или "chats"
    description: "Описание агента"
    icon_name: "nightlight"
    color_class: "bg-indigo-600"
    is_active: true
```

## ⚠️ Важно

- После изменения YAML файла **обязательно** запустите `sync_agents_from_config.py`
- Изменения в БД **не синхронизируются обратно** в YAML (YAML - источник истины)
- Для быстрых тестов можно использовать `edit_prompts.py`, но лучше работать через YAML

## 🔧 Альтернативные способы редактирования

### Через интерактивный скрипт

```bash
python scripts/edit_prompts.py
```

Этот способ удобен для быстрых правок, но изменения не попадут в git автоматически.

### Через API (если реализовано)

Можно добавить эндпоинт для редактирования через веб-интерфейс, но рекомендуется использовать YAML для версионирования.
