# Демонстрация функционала динамического padding-bottom

## Что было сделано:

1. **Модифицирован `useChatInputLayout.js`**:
   - Добавлен параметр `textareaRef` для получения доступа к textarea
   - Обновлена функция `calculatePaddingBottom()` для учета высоты textarea
   - Добавлен `ResizeObserver` для отслеживания изменений высоты textarea в реальном времени

2. **Обновлен `Chat.jsx`**:
   - Добавлена передача `textareaRef` в `useChatInputLayout`

## Как это работает:

### Базовая логика:
- **Базовый padding**: 80px для input области
- **Reply-блок**: +100px при наличии reply
- **Файлы**: +80px + 20px за каждый дополнительный файл
- **Textarea высота**: +разница между текущей и базовой высотой

### Формула расчета:
```
paddingBottom = 80px (базовый)
               + 100px (если есть reply)
               + 80px + 20px * (файлы - 1) (если есть файлы)
               + max(0, текущая высота textarea - базовая высота textarea)
```

### Базовая высота textarea:
- Мобильные: 36px (min-h-[36px])
- Десктоп: 40px (min-h-[40px])

## Тестирование:

1. Откройте приложение в браузере
2. Начните вводить много текста в textarea
3. Обратите внимание, как padding-bottom автоматически увеличивается
4. Добавьте reply-блок или файлы - padding продолжит динамически подстраиваться
5. Удалите текст/файлы/reply - padding вернется к исходному значению

## Преимущества:

- **Реактивность**: Изменения применяются мгновенно при помощи ResizeObserver
- **Точность**: Учитывается фактическая высота textarea, а не количество строк
- **Совместимость**: Работает вместе с существующей логикой для reply и файлов
- **Производительность**: Оптимизировано с использованием useCallback и useRef

## Технические детали:

- Используется `ResizeObserver` для отслеживания изменений размера textarea
- Логика интегрирована в существующий хук `useChatInputLayout`
- Сохранена обратная совместимость с текущим функционалом
